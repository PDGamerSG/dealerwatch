# DealerWatch: front-running investigator for fund houses

> Rehearsal build (29 Oct 2026). All data is synthetic. No real person, account or customer record is used.

## The problem, in one number
SEBI's Axis Mutual Fund front-running order (24 Jul 2026) barred the former chief dealer for 7 years and treated Rs 30.56 crore as disgorgement. The trades ran for months through conduit accounts, and the case was proved by joining chats and call records to trades. Fund houses keep dealer-desk recordings, order blotters and KYC in separate systems, so that join is manual and slow. SEBI requires AMCs to run an institutional mechanism to deter and detect front-running.

## Who it is for
The AMC compliance officer. KPI: time from alert to a defensible case file, and false alarms per 100 alerts.

## What it does (one vertical slice)
1. **Detect (code only).** For every large fund order, find accounts that traded the same side shortly before and the opposite side shortly after (a "sandwich"). Deterministic score from repeat count, profit and timing.
2. **Gather (read-only agent tools).** Pull the dealer's calls in the 3 hours before the order where the other party is in the account's link network. Transcribe (Sarvam code-mixed ASR, or replayed transcripts offline).
3. **Extract (LLM, grounded).** Find leak cues (scrip, side, size, time) in the call. Every cue must cite utterance ids that exist and quote text that is really there; anything else is dropped. Transcripts are treated as untrusted data.
4. **Link (code).** Graph of dealer -> relative -> shared phone/email/bank/device -> trading account.
5. **Verify (code).** A 9-link evidence chain: order, pre-trade, post-trade, profit, repeat pattern, link path, call in window, leak cue, clause. Full chain -> recommend ESCALATE; partial -> REVIEW; sandwich only -> DISMISS.
6. **Narrate (LLM, checked).** A short case summary. A checker rejects any citation not in the evidence and any number not in the evidence; on rejection a deterministic template is used.
7. **Decide (human).** The compliance officer starts review, requests info, approves escalation or dismisses. Nothing is escalated automatically. Wording stays "prima facie".
8. **Record.** Every pipeline step and every decision goes into a hash-chained ledger. A verify button proves nothing was edited; the tamper demo shows the exact row where the chain breaks.

## Why it is different
- Vigil (Forge the Future 2026 winner) audits sales calls. DealerWatch joins **what was said on the dealer desk** to **the trades that followed** and **the account links**, which is how SEBI proved Axis MF.
- The LLM never decides. Rules decide; the model extracts and explains, and its output is checked.
- It plugs into the systems an AMC already has: an MFund Plus-style order blotter in, an AMLOCK-style investigation queue out.

## Results on the labelled synthetic universe
See `EVAL.md` (generated by `python -m dealerwatch.eval.harness`). It reports precision, recall and F1 for ESCALATE against a rules-only baseline (escalate any sandwich with score >= 0.5), the REVIEW (abstain) rate, false alarms, and p50/p95 latency per case. Planted cases include an injection attempt inside a call transcript.

## Security and privacy
- Synthetic data only; masked PAN; no customer data.
- Transcript text is never executed as instructions; the recommendation is computed by code.
- Grounding checker on every LLM output; template fallback.
- Hash-chained, tamper-evident audit ledger.
- UI builds the DOM with text nodes only (no HTML injection from transcripts).
- No secrets in code; providers read keys from environment variables.

## Scale path
Stateless pipeline stages; the detector is a windowed join that maps to SQL or Spark on the full tape; ASR and LLM calls are per-candidate and cached; ledger heads can be anchored externally. Multi-AMC tenancy by data partition.

## Known gaps
- Synthetic universe only; real deployment needs the AMC's blotter, recording metadata and KYC feeds.
- Rules extractor is tuned to Hinglish romanised text; Devanagari transcripts need the LLM path.
- Link graph uses exact matches on shared attributes; fuzzy matching (name, address) is future work.
