# Project budget

**Project:** Dealer Watch
**Event:** HackIn Drive 2026
**Requested budget:** **₹50,000**

| Use | Amount | Why it is needed |
|---|---:|---|
| AWS persistent backend, storage and TLS | ₹12,000 | Keep SQLite state, archived audio, run history and backups on a durable host. |
| Vercel frontend, previews and CI | ₹3,000 | Host the landing page and console, run preview builds, and keep the submission deployment reproducible. |
| Speech, transcription and model service credits | ₹8,000 | Test optional transcription and evidence-summary integrations against approved synthetic recordings. |
| Domain, monitoring, backup and security operations | ₹7,000 | Cover domain and certificate work, uptime checks, snapshots, and operational safeguards. |
| Demo hardware, connectivity and recording | ₹10,000 | Support the live demonstration, browser/device checks, audio playback, and the 2–3 minute pitch video. |
| Presentation assets and contingency | ₹10,000 | Prepare slides, diagrams, submission assets, and cover unexpected hosting or testing costs. |
| **Total** | **₹50,000** | |

The prototype uses synthetic data and deterministic mock/replay providers by default, so the budget is for a reliable demonstration and a small controlled pilot rather than for buying production data.
